# Sistema de Gestión Logística DaniPak

Proyecto para la gestión integral de procesos logísticos, administrativos y comerciales de DaniPak.

## Descripción

Esta aplicación centraliza el control de inventarios, compras, ventas, facturación, movimientos de bodega y seguimiento de logística para mejorar la eficiencia operativa.

## Objetivo

Implementar una solución que permita gestionar de forma segura y ordenada los datos de clientes, proveedores, productos, pedidos y rutas de distribución.

## Alcance

- Registro y consulta de inventarios.
- Administración de clientes y proveedores.
- Procesamiento de pedidos y control de facturas.
- Gestión de bodegas y movimientos de stock.
- Seguimiento de entregas y logística.
- Generación de reportes básicos.

## Requisitos

- Sistema operativo compatible con la aplicación.
- Base de datos configurada según la documentación.
- Permisos de usuario para acceso al módulo administrativo.

## Uso

Una vez instalada, ingrese con un usuario autorizado y utilice los módulos disponibles:

- Inventarios
- Compras
- Ventas
- Clientes
- Proveedores
- Bodegas
- Logística
- Reportes
